# PROBE

## Project Summary

PROBE (Proactive Rule Oriented Belief Engine) wraps a frozen language model in a loop that forms an explicit belief about the hidden RULES of a new environment, tests that belief, detects contradictions, and revises the belief, including when the rules change mid episode.

The committed research contribution is rule level belief plus contradiction driven revision under non stationary rules. This is the axis that separates PROBE from Align While Search, which estimates object locations in a static world. Voyager is cited as lineage (it grows skills in a known rule world) rather than as a competitor.

Candidate paper title: PROBE: A Hypothesis Driven Agent Architecture for Novel Environment Adaptation.

The project moves linearly through a staged campaign of capability checkpoints, internal diagnostic bosses, and external benchmark bosses, ending at ARC-AGI-3 as a stress test. See `../notes/ROADMAP.md`. Current stage: Stage 0 (MiniGrid baseline).
